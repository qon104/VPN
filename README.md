# 🌐 VPN Subscription Backend

Это серверная часть (бэкенд) для проекта VPN-подписок. Написан на Python. 
Ниже простое руководство, чтобы понять, какой файл за что отвечает и где писать код.

---

### 📂 Куда смотреть и где лежит код?

* 📁 **app/** — Самая главная папка. Весь рабочий код пишется ТУТ. Внутри лежат настройки, логика работы с пользователями, обработка VPN-серверов и создание ключей. Если хочешь добавить новую функцию или изменить логику сайта — тебе сюда.

* 📁 **alembic/** и 📄 **alembic.ini** — Это система миграций для базы данных. Когда ты меняешь структуру таблиц в коде (например, добавляешь новое поле для пользователя), через эти файлы изменения переносятся в саму базу данных. Руками тут файлы лучше не трогать, они генерируются автоматически.

* 📁 **scripts/** — Папка со вспомогательными скриптами. Сюда складываются мелкие утилиты, скрипты для тестов, автоматического создания админа или быстрой очистки базы.

---

### ⚙️ Служебные файлы (настройки окружения)

* 📄 **requirements.txt** — Просто список всех библиотек, на которых работает проект. Сюда дописываются новые модули, если ты устанавливаешь их в проект.

* 📄 **docker-compose.yaml** и 📄 **Dockerfile.txt** — Настройки для Docker. Нужны для того, чтобы развернуть проект одной кнопкой в изолированном контейнере, не устанавливая Python и базу данных прямо на компьютер. Вся магия автоматического запуска описана здесь.

* 📄 **__init__.py** — Пустой технический файл. Он просто говорит Python, что эта папка является модулем и её файлы можно импортировать друг в друга.
